# 0x07. C - Pointers, Arrays and Strings

This project focuses on:

- Memory manipulation
- String searching functions
- Pointer arithmetic
- Multidimensional arrays (2D arrays)

## Tasks

0. memset - Fill memory with a constant byte  
1. memcpy - Copy memory area  
2. strchr - Locate a character in a string  
3. strspn - Get length of prefix substring  
4. strpbrk - Search a string for any set of bytes  
5. strstr - Locate a substring  
6. print_chessboard - Print a chessboard  
7. print_diagsums - Print diagonals of a matrix  

## Requirements

- Allowed editors: vi, vim, emacs  
- Compilation:
- All files must end with a new line  
- Betty style must be followed  
- No global variables  
- No use of printf (except where allowed)  
- Use only _putchar for output  
- Do not push _putchar.c  
- All prototypes must be in main.h
