# More malloc, free

This project contains C functions that demonstrate dynamic memory allocation using:

- malloc
- free
- exit

## Files

### 0-malloc_checked.c
Allocates memory using malloc and exits with status 98 if malloc fails.

### 1-string_nconcat.c
Concatenates two strings using dynamic memory allocation.

### 2-calloc.c
Allocates memory for an array and initializes all bytes to zero.

### 3-array_range.c
Creates an array of integers from min to max.

## Compilation

All files are compiled using:

gcc -Wall -pedantic -Werror -Wextra -std=gnu89# More malloc, free
