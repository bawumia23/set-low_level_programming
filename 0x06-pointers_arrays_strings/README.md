# 0x06. C - More Pointers, Arrays and Strings

This project focuses on strengthening understanding of:
- Pointers
- Arrays
- Strings manipulation in C

## Tasks

0. strcat - Concatenate two strings  
1. strncat - Concatenate with limit  
2. strncpy - Copy string with limit  
3. strcmp - Compare two strings  
4. reverse_array - Reverse integer array  
5. string_toupper - Convert to uppercase  
6. cap_string - Capitalize words  
7. leet - Encode string into 1337  

## Requirements

- Allowed editors: vi, vim, emacs nano  
- Compiled on Ubuntu 20.04 using:
- All files end with a new line  
- Betty style must be followed  
- No global variables  
- Max 5 functions per file  
- No standard library functions like printf  
- Use only _putchar for output  
- All prototypes are in main.h
