# Static Libraries Project

## Description
This project creates a static library (libmy.a) containing custom C functions.

## Files
- main.h: Function prototypes
- *.c: Source files
- libmy.a: Static library
- create_static_lib.sh: Script to build liball.a

## Compilation
gcc -Wall -Werror -Wextra -pedantic -std=gnu89
