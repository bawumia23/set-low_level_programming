# malloc_free

This project contains exercises on dynamic memory allocation in C using:

- malloc
- free

## Tasks

### 0-create_array.c
Creates an array of chars and initializes it with a specific character.

### 1-strdup.c
Returns a pointer to a newly allocated space in memory containing a copy of a string.

### 2-str_concat.c
Concatenates two strings into a newly allocated memory space.

### 3-alloc_grid.c
Creates a 2-dimensional array of integers initialized to 0.

### 4-free_grid.c
Frees a previously allocated 2-dimensional grid.
