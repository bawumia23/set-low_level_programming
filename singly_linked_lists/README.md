# Singly Linked Lists (C Project)

This project implements basic operations on a singly linked list in C.

## Files

- `lists.h` - Header file containing structure and function prototypes
- `0-print_list.c` - Prints all elements of a list
- `1-list_len.c` - Returns number of nodes in the list
- `2-add_node.c` - Adds a node at the beginning
- `3-add_node_end.c` - Adds a node at the end
- `4-free_list.c` - Frees the entire list

## Compilation Example

```bash
gcc -Wall -pedantic -Werror -Wextra -std=gnu89 *.c -o output
